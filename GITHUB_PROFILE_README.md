## 🚀 Featured Projects

### 🏦 [Event-Sourced Digital Banking Ledger with CQRS](https://github.com/ishaannegi/Event-Sourcing-Digital-Banking-Ledger-with-CQRS-Architecture)
Enterprise-grade financial ledger engineered with **Command Query Responsibility Segregation (CQRS)** & **Event Sourcing**.
- **Double-Entry Bookkeeping**: Strict atomic debit/credit constraints ensuring non-negative balances.
- **Audit & Replay**: Point-in-time balance reconstruction down to exact millisecond timestamps and event versioning.
- **High-Performance Caching**: Sub-15ms Redis query caching with automated TTL eviction and write-side cache invalidation.
- **Async Event Streaming**: Decoupled Kafka projection worker streaming real-time event updates to PostgreSQL read views.
- **Optimistic Concurrency**: JPA `@Version` locking with automatic exponential backoff retry interceptors under heavy load.
- **Security & UI**: JWT authentication, fine-grained RBAC, interactive live CQRS state inspector, and luxury dark-mode React SPA dashboard.
**Tech:** Java 21 · Spring Boot 3 · PostgreSQL · Apache Kafka · Redis · React (Vite) · Tailwind CSS · Docker Compose

### 🎯 [AI Career Compass](https://github.com/ishaannegi/interview_pf)
Full-stack AI-driven career-prep platform deployed on Vercel — dual-mode PostgreSQL/SQLite persistence, resume ATS scoring, live audio-transcribed mock interviews with AI feedback, and adaptive code-gap quizzes across three product modules.
**Tech:** Flask · PostgreSQL · SQLite · Gemini API · Whisper API · Vercel

### 🤖 [Reinforcement-Learning CPU Scheduler](https://github.com/ishaannegi/reinforcement_scheduler)
Epsilon-greedy Q-learning CPU scheduler benchmarked against FCFS, SJF, SRTF, and Round Robin, with a shared metrics engine and a real-time visualization frontend served via Flask REST API.
**Tech:** Python · Flask · NumPy · Q-Learning

### 📊 [Task Manager — DevOps Pipeline](https://github.com/ishaannegi/tskmgr)
